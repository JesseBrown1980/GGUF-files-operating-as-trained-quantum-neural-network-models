Tag: DERIVED (steps 1-7). Numbers that check it are in F1b onward.

Model read: H = x n + (u/N)[n0 n + n+ n-] + (1/N)(P + P^dag) - y[a0^dag(a+ + a-) + h.c.], n = n+ + n-,
P = a+^dag a-^dag a0 a0, in units JN = 1. delta = x + u, u = 1.

Step 1, number-conserving modes. Work on |n+, n-> with n0 = N - n. Define b+, b- as plain bosons on
(n+, n-). Then exactly
   P = b+^dag b-^dag sqrt((N-n)(N-n-1))        [n acts first on the ket]
   a0^dag a+ = b+ sqrt(N-n+1),   a+^dag a0 = b+^dag sqrt(N-n)
   diag = delta n - (u/N)(n+^2 + n-^2 + n+ n-).
Could fail: only if the state reaches n comparable to N. That is the depletion bound, not an assumption
about a0's phase; no c-number a0 is used anywhere.

Step 2, expansion with s = y sqrt(N) fixed, N large:
   H = H2 + (1/N) H1 + O(1/N^2)
   H2 = delta n + (b+^dag b-^dag + b+ b-) - s Sum(b + b^dag)
   H1 = -u(n+^2 + n-^2 + n+n-) - [b+^dag b-^dag (n + 1/2) + h.c.] + (s/2) Sum[b (n - 1) + b^dag n]
Could fail: (i) when n/N is not small; (ii) when s grows with N faster than sqrt(N) y held at scale;
(iii) after the time when the expansion's secular terms ~ t e^(2 gamma t)/N reach order 1.

Step 3, s and a combinations: b_s = (b+ + b-)/sqrt2, b_a = (b+ - b-)/sqrt2, b = (q + i p)/sqrt2.
   H2 = ((delta+1)/2) q_s^2 + ((delta-1)/2) p_s^2 - 2 s q_s + ((delta-1)/2) q_a^2 + ((delta+1)/2) p_a^2 + const.
Equations: q_s' = (delta-1) p_s, p_s' = -(delta+1) q_s + 2s.
   q_s'' = gamma^2 (q_s - q_eq), gamma^2 = 1 - delta^2, q_eq = 2s/(1+delta).
From q_s(0) = p_s(0) = 0 in the mean:
   qbar(t) = -q_eq (cosh(gamma t) - 1),   pbar(t) = 2 s sinh(gamma t)/gamma.
Could fail: 1 + delta = 0 needs the limit (cosh - 1)/(1+delta) -> (1-delta)t^2/2 = t^2, kept finite.
At delta = +1, gamma = 0, q_s is frozen: qbar = 0 at this order, so A1 and C1 both START at next order in 1/N.

Step 4, A is a complex Gaussian at this order. A = a0^dag a+ + a-^dag a0 -> sqrt(N)(b+ + b-^dag)
 = sqrt(N)(q_s + i p_a), and [q_s, p_a] = 0. So
   <A> = sqrt(N) qbar, real.  A1 = 2|<A>|/N = 4|y|(cosh(gamma t) - 1)/(1+delta).     <- the law's A1

Step 5, fluctuations, vacuum start. Same H2 quadratics, so
   <q_s^2>_c = <p_a^2>_c = (1/2)[cosh^2 + ((1-delta)/(1+delta)) sinh^2]   (gamma t inside)
   <p_s^2>_c = <q_a^2>_c = (1/2)[cosh^2 + ((1+delta)/(1-delta)) sinh^2]

Step 6, the C1 operator. From Psi(x) = Sum a_m e^(imkx) (L = 1),
   average over x of Psi^dag(x)Psi^dag(x+r)Psi(x+r)Psi(x)
     = N(N-1) + 2 X cos kr + 2 n+n- cos 2kr,  X = n0 n + P + P^dag.
So C1 = 2<X>/(N(N-1)), C2 = 2<n+n->/(N(N-1)) IF the engine normalises by N(N-1): to be checked in the engine.
And A^dag A = n0 n + P + P^dag + n0 + n+ as an operator (order a0 a0^dag = n0 + 1, a- a-^dag = n- + 1), so
   X = A^dag A - n0 - n+
and hence, for any state, A1^2/(2 C1) = ((N-1)/N) |<A>|^2 / (<A^dag A> - <n0 + n+>).
That is the stated identity. It needs no parity and no approximation; note [A, A^dag] = n- - n+.
Leading order: X/N -> <n + b+^dag b-^dag + b+ b-> = <q_s^2 ...>:
   n+ + n- = (q_s^2 + p_s^2 + q_a^2 + p_a^2)/2 - 1,   b+^dag b-^dag + b+b- = (q_s^2 - p_s^2 - q_a^2 + p_a^2)/2
   sum = q_s^2 + p_a^2 - 1.    <- clean: X/N = |z|^2 - 1, z = q_s + i p_a = A/sqrt(N).
   <X>/N = qbar^2 + 2<q_s^2>_c - 1 = qbar^2 + (2/(1+delta)) sinh^2.
   C1 = 2<X>/N^2 = 4 sinh^2/((1+delta)N) + 8 y^2 (cosh-1)^2/(1+delta)^2 = 4 sinh^2/((1+delta)N) + A1^2/2.  <- the law's C1
Could fail: drops 1/N relative. Those terms are what task 5 computes.

Step 7, V^2 and D2.
   V^2 = A1^2/(2 C1) = qbar^2/(qbar^2 + sigma^2), sigma^2 = (2/(1+delta)) sinh^2,
   Y = qbar^2/sigma^2 = (2 N y^2/(1+delta)) tanh^2(gamma t/2), using (cosh-1)/sinh = tanh(gamma t/2).   <- the law's Y
   <B> = <b-^dag b+> = |<b+>|^2 + <b-^dag b+>_c. <b-^dag b+>_c = 0 by the y=0 charge symmetry of the Gaussian part.
   |<b+>|^2 = (qbar^2 + pbar^2)/2, so D2 = 2<B>/N = 2 y^2[(cosh-1)^2/(1+delta)^2 + sinh^2/gamma^2].  <- the law's D2

Limits, DERIVED here, all forms kept finite:
   delta = -1:  A1 = 4|y|t^2, C1 = 8 t^2/N + 8 y^2 t^4, Y = N y^2 t^2, D2 = 2y^2(t^4 + t^2).
   delta = +1:  A1 = 0, sigma^2 = 0 at this order, C1 = 0, V^2 is 0/0 in the leading forms; Y -> 0 as the limit from inside the band; D2 = 2 y^2 t^2.
   |delta| > 1: gamma = i w, w^2 = delta^2 - 1: cosh -> cos(wt), sinh^2 -> -sin^2(wt), tanh^2 -> -tan^2(wt/2)
       delta > 1: Y = -(2Ny^2/(1+delta)) tan^2(wt/2) < 0, sigma^2 < 0 (a Gaussian with SUB-shot-noise in |z|^2): C1 < 0 for |Y| < 1, V^2 < 0 there;
                  pole at Y = -1; V^2 > 1 for |Y| > 1.
       delta < -1: 1+delta < 0, Y = (2Ny^2/|1+delta|) tan^2(wt/2) >= 0, V^2 in [0,1), reaching 1 at wt = pi; 0/0 at wt = 2 pi.

Reading the law: z = A/sqrt(N) is a complex Gaussian with mean qbar and total excess variance sigma^2.
V^2 = |<z>|^2/<|z|^2 - 1>. So the law is NOT a statement about amplitude alone; it is the ratio of the mean to the
normal-ordered second moment of one complex variable, A itself, whatever the size of that variable.
This is the handle task 4 uses.
